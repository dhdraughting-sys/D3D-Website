What happens next

From request to running in four steps

1

We reply

We confirm the programs, the period and the price with you before anything is built.

2

We build your installer

Locked to your licence. We email you a private download link and, in a separate message, the password.

3

You install it

If Windows shows “Windows protected your PC”, choose More info, then Run anyway. Windows shows this for any new program that is not yet code-signed.

4

You are ready

Your licence runs for the period you chose and the programs open straight away. When it runs out the program asks for a new passcode and your files are kept.

Questions

Before you ask

Does it need the internet?

Only to download. The licence is checked on your PC and works offline.

Which Windows versions?

Windows 10 and 11.

Can I read the manual first?

Drawing Platform quick manual (PDF)

Can I use it on more than one PC?

Each licence covers one PC. If you need the software on more than one PC, tell us how many in the notes box when you request and we will quote for each.
